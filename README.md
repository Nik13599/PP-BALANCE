# PP Balance — Match-3 Demo

Полностью автономный пример Telegram Mini App в одном HTML-файле.

## Запуск

1. Откройте `index.html` локально в браузере.
2. Для публикации загрузите репозиторий на любой HTTPS-хостинг.
3. Укажите публичный HTTPS URL приложения в BotFather.

## В демо есть

- адаптивный мобильный интерфейс;
- поле 8×8;
- обмен соседних фишек;
- проверка допустимого хода;
- горизонтальные и вертикальные совпадения;
- каскады и комбо;
- очки, ходы и цель уровня;
- бустеры «Микс» и «Ложка»;
- ежедневная награда;
- рейтинг и профиль;
- сохранение прогресса в `localStorage`;
- базовая поддержка Telegram WebApp API.

## Структура

Текущая версия находится целиком в файле `index.html` и не требует установки npm-зависимостей.

## Ограничения демо

Это клиентский прототип. Для коммерческого релиза потребуются backend, база данных, серверная проверка результатов, реальная таблица лидеров, Telegram Stars и административная панель.
